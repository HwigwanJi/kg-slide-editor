# 케인즈그룹 (Keynes Group) 장표 디자인 시스템

한국 공공기관·정책컨설팅 보고서용 **고밀도 분석 장표**를 설계하기 위한 디자인 시스템입니다.
이 시스템의 목표는 특정 보고서를 복제하는 것이 아니라, 한국형 정책컨설팅 보고서가 요구하는
**시각 문법**(고정 위계 헤더 + 반(半)프리폼 분석 본문)을 일관되게 재현하는 것입니다.

> 핵심 원칙 — 상단 목차 체계는 고정된 위계형 구조로 유지하고, 본문은 근거·쟁점·시사점·절차·검토사항
> 간 관계를 설명하기 위해 도형·표·화살표·콜아웃을 활용하는 **반프리폼 고밀도 정책컨설팅 장표**로 구성한다.

## 1. 회사·산출물 컨텍스트

**케인즈그룹 (Keynes Group)** 은 실태조사·정책연구·전략컨설팅을 수행하는 컨설팅 기관으로,
정부·공공기관 대상 연구용역 제안서 및 착수·중간·결과 보고서를 주요 산출물로 한다.

조직 본부 (용역사 소개 기준):
| 본부 | 영문 | 역할 |
|---|---|---|
| 실태조사 본부 | RESEARCH | 조사기획·통계기반 실태조사·정책연구 |
| 전략컨설팅 본부 | STRATEGY | 경영·사업전략 수립, 신사업·미래성장동력 |
| HR·조직 본부 | PEOPLE & ORG. | 조직진단·인사제도, 조직문화·변화관리 |
| 지속가능경영 본부 | ESG & SUSTAIN. | ESG 전략 수립, 중대성 평가·보고서 |

**이 디자인 시스템이 다루는 산출물 = 정책컨설팅 보고서 장표(슬라이드).** 별도의 웹/앱 제품 UI는 없으며,
"제품"은 곧 보고서 장표 그 자체다. 따라서 본 시스템의 1차 산출물은 `slides/` 의 장표 템플릿이다.

## 2. 장표의 고정 위계 구조

모든 콘텐츠 장표는 아래 위계를 따른다. (상단은 고정, 본문은 유연)

```
┌───────────────────────────────────────────────────────────────┐
│ [01]│ 섹션 제목                                  [ II · 챕터명 ]│  ← 네이비 헤더 (고정)
│     │ 세부 주제·관점                              (떠 있는 탭)  │
├───────────────────────────────────────────────────────────────┤
│        ▌ 헤더 메시지 — 장표의 핵심 주장 한 문장 (명사형 종결)    │  ← 메시지 띠
├───────────────────────────────────────────────────────────────┤
│ ▌본문 영역 제목 ─────────────────────────────  (밑줄형)        │
│                                                                 │
│     [ 반프리폼 분석 본문: 박스·표·화살표·콜아웃·번호 ]          │  ← 본문 (유연)
│                                                                 │
│     ▌시사점/결론 배너                                           │
├───────────────────────────────────────────────────────────────┤
│ 자료: 출처              페이지            Keynes Group 로고      │  ← 푸터
└───────────────────────────────────────────────────────────────┘
```

1. **최상위 챕터 탭** (우상단, 흰색 라운드 탭) — 로마숫자 + 대분류명. 보고서 전체 구조상 위치.
2. **섹션 번호 + 제목** (좌상단, 네이비 헤더) — 큰 숫자 / 굵은 제목 / 작은 부제.
3. **세부 주제·관점** — 섹션 내 장표별 분석 관점.
4. **헤더 메시지** — 제목이 아니라 *주장*. `[상황·변화] + [대응 방향] + [필요/확보/제고/고도화]`, 명사형 종결.

## 4. CONTENT FUNDAMENTALS — 카피·문체

**문체 = 한국 공공기관 정책보고서 / 컨설팅 보고서 문체.** 광고·마케팅 카피가 아니다.

- **인칭/톤:** 1·2인칭 없음. 객관·분석적 서술. "우리/여러분" 금지. 판단 주체를 드러내지 않는다.
- **종결:** **명사형 종결을 선호** — …필요 / …확보 / …제고 / …고도화 / …검토 / …정합 / …전환.
  서술형이 필요하면 "~할 필요", "~가 정합적" 처럼 단정적·압축적으로.
- **밀도:** 짧고 밀도 있게. 한 박스 = 한 메시지. bullet은 1~2행. 수식어 최소화.
- **헤더 메시지 예시 (실제 톤):**
  - "현행 제작비 세액공제는 최저한세·비환급·영세구조가 중첩되어 실제 환급 실효성이 제약 — 환급형 전환 검토 필요"
  - "주요국은 납부세액과 무관하게 현금을 지급하는 환급형 구조 — 국내 비환급 구조와 근본적 차이"
- **권장 어휘:** 필요·확보·제고·고도화·검토·분리·연계·전환·구조화·체계화·정합성·신뢰도·타당성·활용성·
  지속가능성·기준 마련·단계적 적용·보완 필요.
- **금지 어휘/표현:** 혁신적·압도적·완벽한·놀라운·획기적·차원이 다른, 내용 없는 "미래지향적",
  마케팅 카피, 판단 기준 없는 추상 표현, 이모지(emoji 미사용).
- **숫자/단위:** 단위는 작게 별도 표기(단위: 억 원). 출처는 푸터 또는 각주에 명시. 미확정 수치는 `*` 표기 + "재확정 필요".
- **영문 사용:** 라벨 보조용으로만 (INPUT/STEP/OUTPUT, Core/Rotating/Ad-hoc Module, Table of Contents, Part III). 본문은 한국어.

## 5. VISUAL FOUNDATIONS — 시각 기반

### 색상
- **스파인 = 네이비/블루 농도 스케일.** Office "Dark Blue" 계열(`#1F497D` / `#17375E` / `#DCE6F2`)을 기반으로 함 —
  한국 공공·정책보고서의 사실상 표준 팔레트. 위계는 **색을 늘리는 게 아니라 파란 계열의 농도 차이**로 만든다.
- Deep Navy `#17375E` 헤더 / Primary Navy `#1F497D` 박스·TOC·핵심 라벨 / Medium Blue `#4F81BD` 번호·화살표 /
  Pale Blue `#DCE6F2` 제목바·카드헤더 / Tint `#F4F8FC` 본문배경.
- **의미색은 의미가 있을 때만:** Accent Red `#C00000` (위험·제외·중복·유의·비교기준), Accent Green `#1E7A46` (성장·증가·긍정, 제한적).
- 전체 톤: 안정·신뢰. 강조색 남발 금지.

### 타이포
- **Pretendard** (300~900) 단일 본문 패밀리. 제목 700/800, 본문 400/500, 라벨 600/700.
- 브랜드 워드마크는 **Didone 계열 세리프** — 영문 디스플레이 악센트(표지·목차·간지 제목, 로마숫자)에만 제한적으로
  `--font-serif`(Playfair Display/Georgia)로 호응. 본문에는 세리프 사용 금지.
- **A4 가로(1280×905) 기준** 최소 가독 13~14.5px(표/캡션), 본문 16px, 소주제 20px, 메시지 23px, 섹션번호 40px. 이보다 작게 쓰지 않는다.

### 형태·간격·엘리베이션
- **라운드 최소** — 박스 2px, 카드 4px, 탭 6px, 번호 원형만 pill. 공공보고서 톤은 거의 각진 느낌.
- **그림자 거의 없음** — 떠 있는 챕터 탭과 콜아웃에만 아주 약하게(`--sh-tab`/`--sh-card`). 본문 박스는 1px 테두리로 구분.
- 테두리: 표·박스 1px(`--line` cool blue-gray), 본문 제목 밑줄 2px, 좌측 강조바 3px(해석 박스 등 제한적).
- 간격: 4px 베이스(`--sp-*`). 본문 좌우 여백 28px.

### 배경·이미지·모션
- **배경:** 본문 장표는 흰색. 표지·목차·간지·마무리만 네이비 그라데이션(radial/linear, `#1F497D`↔`#17375E`↔`#0E1C30`).
  전면 사진은 헤더 우측에 어둡게(opacity .5) 마스크 페이드해 텍스트 가독 확보 — 선택 사항(`.kg-header__media`).
- **모션 없음.** 인쇄·발표용 정적 장표. 호버/프레스 상태 개념 없음(인터랙티브 제품이 아님).
- **그라데이션 사용 규칙:** 표지/간지의 네이비 딥 그라데이션과 간트/지표 바의 blue→navy 그라데이션만 허용.
  보라빛·무지개·과한 컬러 그라데이션 금지.
- 이미지 톤: 쓰는 경우 차갑고 어두운 네이비 오버레이로 통일.

## 6. ICONOGRAPHY — 아이콘·도식

- 이 시스템은 **이모지·이모티콘·유니코드 픽토그램을 쓰지 않는다.** "아이콘 3개 + 짧은 설명" 식 카드형 장표도 금지(§9).
- **도식 요소가 곧 아이콘 역할**을 한다: 번호 원형 라벨(①②③), 화살표(›/▶), `+` 연결자, 셰브론, 점선 연결선,
  제목바, 콜아웃, 스탬프(예: *Illustrative*), 강조행, 누수/제외 라벨. 모두 CSS로 구현(`kg-slide.css`).
- **이모지·이모티콘·유니코드 픽토그램 미사용.** 화살표·체크는 텍스트 글리프(`›`,`▶`,`‹`) 또는 CSS mask SVG(체크 불릿)로 처리.
- 자체 아이콘 폰트/스프라이트는 원본에 없음. 추가 라인 아이콘이 꼭 필요하면 **Lucide**(`https://unpkg.com/lucide`)를
  네이비 단색·1.75px 스트로크로 절제해 사용하고, 본문 논리와 무관한 아이콘은 넣지 않는다.
- **로고(유일한 래스터 브랜드 자산):**
  - `assets/keynes-group-logo.png` (컬러) — **밝은 배경**(본문 푸터, 흰 장표)에 사용.
  - `assets/keynes-group-logo-shadow.png` (반전/음영) — **네이비 배경**(표지·목차·간지·마무리)에 사용.
  - 마크는 네이비 풍차형 + 마젠타 슬리버 + 도트. 마젠타는 로고에만 존재하며 장표 본문 팔레트에는 끌어오지 않는다.
- SVG는 직접 그리지 않는다. 도식은 위의 CSS 프리미티브를 조합.

## 8. 사용법 (요약)

새 장표를 만들 때:
1. 내용의 **논리 유형**을 판단 → 레이아웃 패밀리(A~F) 선택.
2. 고정 헤더(섹션번호·제목·세부주제·챕터탭) + **헤더 메시지**(주장) 먼저 확정.
3. 본문을 박스·표·화살표·콜아웃으로 구조화 — 근거와 해석을 분리, 시사점은 결론 배너로.
4. `colors_and_type.css` + `kg-slide.css`를 링크하고 `.kg-slide` 안에서 클래스를 조합.
5. 점검: 상단 위계 명확? 헤더 메시지가 주장인가? 단순 카드 나열이 아닌가? 도형이 분석 관계를 설명하는가?
   정보 밀도는 높되 읽는 순서가 분명한가? 공공보고서 톤인가?

> 예시 장표를 그대로 따라 하지 말 것. 동일한 문법·밀도를 유지하되 입력 내용에 맞는 새 구조를 설계한다.
