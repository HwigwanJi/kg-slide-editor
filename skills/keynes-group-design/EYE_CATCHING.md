# 시선을 사로잡는 장표 문법 (EYE_CATCHING.md)

BPS/ECG 우수 장표에서 추출한 **"나열 탈피 → 시선 집중"** 규칙. 지금 우리 장표의 문제는 *나열식*.
아래 문법을 지키면 한 장이 **하나의 그림**으로 읽힌다.

## 1. 컴포넌트가 하는 "말" (의미-형태 매핑)
| 컴포넌트 | 무슨 말을 하려고 | 예시 |
|---|---|---|
| **네이비 대형 헤더바** | "이 영역이 이 장의 큰 두 축이다" | 갱신 근거 / 위수탁 규정 · 객관성 / 유의성 |
| **연파랑 서브헤더바(이탤릭)** | "그 축이 확보하려는 목표" | *비계량 지표…객관성 확보* |
| **좌 차트 + 우 결론** | "데이터가 있으니 결론은 이렇다" | 산점도 → 평균 5.99% |
| **점선 하향 화살표 체인** | "근거가 단계적으로 쌓여 결론에 도달" | 근거1⋯근거2⋯→결론 |
| **red 볼드 결론 박스** | "그래서 이것이 요구된다"(단 1개) | *이윤 보장·적립 요구* |
| **⊕ 합성 노드 / 상하 결합** | "A와 B가 합쳐져 C가 된다" | 직무+역량 / 성과+관리 |
| **스펙트럼 축 + 3박스(농도↑)** | "낮음→높음 중 이게 최적" | GRS→BOS→**BARS** |
| **번호 세그먼트 휠 + 방사 콜아웃** | "핵심 키워드 N개가 한 주제를 구성" | MZ 5대 트렌드 |
| **수식 인용 박스(점선)** | "방법론의 학술적 근거" | Z=…, T-Score=… |

## 2. 박스 안 / 밖 텍스트 규칙 ★
- **박스 안** = 확정된 개념·데이터·키워드. 짧게(명사·수치·1줄). 헤더바=이름, 본문=정의/근거.
- **박스 밖** = 흐름·관계 설명. 화살표 라벨, 축 라벨(低수준/高수준), 각주(*출처), 다이어그램 캡션.
- **강조 위계**: 박스 헤더(흰/네이비) → 박스 내 밑줄 인라인 강조(핵심 어구만) → red는 결론 1곳.
- **한 박스 = 한 메시지**. 두 개면 박스를 나눈다.
- 불릿은 박스 안에서 `▷`/`▪`로, 2줄 이내. 긴 설명은 들여쓰기 하위줄.

## 3. "시선 집중" 레이아웃 3원칙
1. **중심 오브젝트 1개**: 휠·큰 다이어그램·대형 플로우를 화면 중앙/좌측에 크게 두고, 나머지는 그 주변 위성.
   (나열형 3~4칸 균등분할 지양 — 크기 위계를 준다.)
2. **좌 정형 60% : 우 비정형 40%**: 좌측은 구조도/차트(안정), 우측은 콜아웃·결론(변주).
3. **시선 유도선**: 점선/화살표/⊕로 "읽는 순서"를 물리적으로 그린다. 눈이 따라가게.

## 4. 지금 우리 장표의 문제 → 처방
- ✗ 4칸 균등 카드 나열, 박스마다 같은 높이·같은 패턴 → ✓ 크기·형태 위계(중심1+위성)로 재구성.
- ✗ 차트가 작고 텍스트가 김 → ✓ 차트/다이어그램을 크게, 텍스트는 키워드화.
- ✗ 연결선이 장식 → ✓ 근거→결론 시선 유도선으로 사용, red 결론 1곳으로 수렴.
- ✗ 모든 박스 무채색 균질 → ✓ 네이비 헤더바로 "축"을 세우고 그 아래를 무채색으로.

> 핵심: **"한 장 = 하나의 도해(圖解)"**. 박스를 나열하지 말고, 중심 오브젝트 + 위성 콜아웃 + 수렴 결론으로 **눈의 동선**을 설계한다.
