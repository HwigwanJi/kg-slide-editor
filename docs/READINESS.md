## 1. 검증된 것

빌드가 통과하는지가 아니라 **실제 장표로 확인했는지**를 기준으로 적는다.

| 영역 | 확인 방법 | 결과 |
|---|---|---|
| 저장계약 v5 | 3개 장표를 임포트·편집·저장·재열기 | 패치 보존 |
| 원본 불변 + 패치 덧씌움 | `source.html` 해시가 편집 후에도 동일 | 유지 |
| 삭제(묘비) | 원본 노드 삭제 후 되살리기 — 서식까지 복원 | 동작 |
| 흐름 떼어냄 | 떼어낸 뒤 위계 CSS가 유지되는지 브라우저 실측 | 통과(아래 주석) |
| 개별 서식 오버라이드 | 글자 크기만 바꾸고 색·굵기가 위계를 따르는지 | 통과 |
| 넘침 검사 | 3개 장표 62건 → 오탐 제거 후 4건 | 실측 |
| 도형(SVG) 슬롯 | 라이브러리 도형을 장표에 넣고 글자·색 편집 | 동작 |
| AI 수정 경로 | `npm run apply` 로 커맨드 적용 — 재굽기 없음 | 확인 |
| PNG 프리뷰 | Playwright 로 3장 렌더 | 동작 |
| pptx 텍스트 추출 | 원본 56쪽 → 71,179자, 한글 정상 | 동작 |

**떼어냄 주석** — 이건 한 번 틀렸다가 고친 자리다. 처음엔 떼어낸 노드를
`.kg-detached-layer` 로 옮겼는데, 그러면 `.concl__2step .kgx-flow .n{font-size:13.5px}`
같은 조상 선택자가 끊어져 글자가 13.5px에서 10px로 주저앉았다.
지금은 **노드를 옮기지 않고 제자리에서 절대배치**하고 좌표만 offsetParent 기준으로 환산한다.
떼어냄이 이상하면 이 설계를 먼저 의심할 것.

## 2. 믿지 말 것

작업 중에 실제로 부딪힐 순서대로.

**(1) 자동 시험이 없다.**
`npm run build` 는 타입과 번들만 본다. 회귀는 사람이 브라우저에서 잡는다.
계약(`src/contract/`)이나 `src/core/ids.ts` 를 건드렸다면 반드시 장표를 열어 확인할 것.
이게 지금 가장 큰 구멍이다.

**(2) 대소문자 함정.**
SVG 원소의 `tagName` 은 소문자(`svg`)고 HTML 원소는 대문자(`DIV`)다.
이 한 가지로 두 번 다쳤다 — 도형 안이 편집 단위로 잘못 열렸고, 도형 감지가 다섯 턴 동안 0을 냈다.
태그를 집합과 대조하는 코드를 새로 쓸 때는 `.toUpperCase()` 를 빠뜨리지 말 것.

**(3) 검사기가 남긴 4건.**
`02_직무분류.html` 에 헐거운 박스 1건, 잘린 박스 3건이 남아 있다.
편집기 결함이 아니라 **그 장표의 작도 문제**다. 형제 요소에 `flex` 를 주면
내용이 할당 높이를 밀고 나가 겹친다. `03_모듈설계.html` 처럼 본문을 하나의 grid 로 감싸고
`grid-template-rows` 로 높이를 고정하면 사라진다. 새 장표를 그릴 때 이 방식을 쓸 것.

## 3. 아직 안 만든 것

없어도 작업은 되지만, 필요해지면 그때 만든다(YAGNI).

- 그룹 통째 크기 조절 — 그룹은 DOM 컨테이너가 아니라 논리적 묶음이라 크기 개념이 없다
- 도형 점편집·선편집 — 지금은 슬롯 글자와 CSS 변수 색만 연다. 모양 자체는 SVG 파일을 고친다
- 여러 사람 동시 편집 — 파일 기반 단독 편집 전제
- 실행취소의 영구 보존 — 세션 안에서만 유효하다

## 5. 막혔을 때

| 증상 | 먼저 볼 곳 |
|---|---|
| 편집한 게 사라짐 | AI가 HTML을 다시 구웠는지 — `npm run apply` 경로를 썼어야 한다 |
| 서식이 되돌아감 | 떼어냄 좌표 환산(`src/core/render.ts`의 `placeDetached`) |
| 검사가 헛것을 잡음 | `src/core/overflow.ts` — 슬롯·절대배치 장식은 제외 대상이다 |
| 도형이 안 잡힘 | 태그 대소문자(위 2항) |
| 저장이 거부됨 | 계약 위반이다. 오류 메시지에 어긋난 필드가 찍힌다 |
