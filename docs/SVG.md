# SVG 도해를 시스템에 앉히는 법

CSS 박스로 그릴 수 없는 도해(각도가 있는 배치, 다대다 연결선, 비정형 도형)는 SVG 로 그린다.
문제는 SVG 가 편집기의 기존 편집 단위와 성질이 다르다는 것이다. 그 차이를 어떻게 다룰지 정한다.

## 마주친 긴장

SVG 안 글자도 고칠 수 있어야 한다. 그런데 SVG 내부를 편집 단위로 열면 곧바로 무너진다.
실제로 겪었다 — `<svg>` 의 `tagName` 이 소문자라 불투명 처리를 빠져나가 안쪽까지 스탬핑되었고,
`<text>` 하나하나가 편집 단위가 되면서 요소가 108 개로 부풀고 검사가 글자 하한 미달을 11 건 오탐했다.

**전부 열거나 전부 닫는 두 선택지 사이에서 고르지 않는다. 열 곳만 연다.**

## 세 층

| 층 | 무엇 | 편집기가 하는 일 | 계약에 남는 것 |
|---|---|---|---|
| 도형 | `<svg>` 전체 | 이동·크기·복제·삭제·순서 | 기존 `layout` 그대로 |
| 슬롯 | `data-slot` 이 붙은 `<text>` | 글자만 교체 | 기존 `text` 그대로 |
| 토큰 | svg 안의 `var(--…)` 참조 | 색 재지정 | `style.vars` (신규) |

슬롯 밖의 SVG 내부는 계속 불투명하다. 좌표·경로·그룹은 사람이 손대는 대상이 아니다.
모양을 바꿔야 하면 도형을 다시 그린다(D4 — 점편집은 넣지 않는다).

## 계약에 더할 것 (최소)

```
StylePatch.vars?: Record<string, ColorRef>
```

svg 루트에 CSS 변수를 인라인으로 덮어쓰는 것으로 끝난다.
`--blue-200` 을 다른 토큰으로 재지정하면 그 변수를 쓰는 모든 획과 면이 함께 바뀐다.
SVG 용 `fill`·`stroke` 항목을 따로 만들지 않는다 — 도형마다 칠하는 자리가 달라 일반화되지 않는다.

```
AddedNode.kind 에 'shape' 추가
AddedNode.library?: string      어느 라이브러리 개체에서 왔는지
```

## 스탬핑 규칙

`core/ids.ts` 가 지킬 것은 두 줄이다.

1. `<svg>` 를 만나면 그 자체에만 id 를 주고 내부로 내려가지 않는다. **태그 이름은 대소문자를 맞춰 비교한다.**
2. 예외로 `[data-slot]` 이 붙은 요소는 편집 단위로 인정하고 글자 교체를 허용한다.
   위계(`data-kg-role`)는 붙이지 않는다 — SVG 글자는 KG 위계 CSS 의 사정권 밖이다.

검사도 같은 규칙을 따른다. 슬롯이 아닌 SVG 내부 글자는 하한 검사 대상이 아니다.

## 라이브러리와 장표의 관계

```
library/<이름>.svg     원본. 사람이 열어 보고 남에게 넘기는 것
library/index.json     쓸 자리·크기·슬롯 목록
장표 HTML              같은 마크업의 사본이 인라인으로 들어간다
```

**사본을 두고 동기화하지 않는다.** 장표는 자기완결이어야 미리보기·검사·내보내기가 한 파일만 보면 된다.
원본을 고쳐도 이미 그린 장표는 따라 바뀌지 않는다. 그게 맞다 — 장표마다 글자와 색이 다르게 들어가 있고,
뒤늦게 원본이 밀고 들어오면 사람이 다듬어 둔 것이 사라진다.

추적은 `data-kg-lib="<이름>"` 표시로 한다. 어느 장표가 어느 원본에서 왔는지는 알 수 있어야 한다.

## 언제 SVG 인가

먼저 CSS 로 되는지 본다. 되면 CSS 다. SVG 는 아래일 때만 쓴다.

- 각도가 있는 배치 (육각형 묶음, 방사형)
- 다대다 연결선 (여러 항목이 여러 항목과 이어짐)
- 곡선·비정형 도형

셰브론·사다리꼴·막대·도넛은 이미 KG 컴포넌트에 있다. 다시 그리지 않는다.

## 라이브러리에 넣을 조건

두 장 이상에서 쓰일 것. 한 장에서만 쓰는 도해는 그 장표에 인라인으로 두고 끝낸다.
쓰이지 않는 라이브러리 개체가 쌓이면 고를 때 방해가 된다.

## 남은 순서

1. 스탬핑에 슬롯 예외 추가 (`[data-slot]` 만 열기)
2. `StylePatch.vars` — 계약 v5
3. 선택 탭에 도형 슬롯 목록 (글자 교체) + 토큰 교체
4. 라이브러리에서 도형 넣기 — `insert` 커맨드에 `kind: 'shape'`
5. `tools/lint.mjs` 가 `library/*.svg` 도 검사 (viewBox·토큰 사용·슬롯 정의 일치)
