# 기능 배선 — 무엇이 어디에 있고 어디로 흐르는가

단추가 늘어나는 것을 막기 위한 문서다. **여기 없는 길은 만들지 않는다.**

## 어디에 무엇이 있는가

| 리본 탭 | 다루는 것 | 단추 |
|---|---|---|
| **프로젝트** | 프로젝트 전체 | 프로젝트 열기 · 폴더 쓰기 진단 |
| **홈** | 지금 장표와 편집 | 저장 · 다시 읽기 · 내보내기 · 되돌리기 · 복제 · 삭제 · 참조 복사 |
| **슬라이드** | 장표 낱장 | 새 장표 · 장표 복제 · 장표 파일 지우기 |

프로젝트를 여는 길은 **하나**다. 저장하는 길도 **하나**다.
같은 일을 하는 단추를 둘로 갈라 두면 어느 것을 눌러야 할지 알 수 없게 된다.

## 프로젝트를 여는 흐름

```
[프로젝트 열기]
   │
   ├─ 지난번 폴더가 남아 있나 (IndexedDB)
   │     예 → 권한만 다시 받는다        ─┐  폴더를 찾아 들어갈 필요 없음
   │     아니오 → 폴더 선택 창           ─┤
   │                                      │
   ├─ 못 받았거나 실패                    │
   │     → 토스트로 크게 알린다           │  상태줄 한 줄이면 "눌러도 아무 일 없음" 으로 읽힌다
   │     → 여기서 끝                      │
   │                                      ▼
   └─ 받았다 → 지금 장표를 저장 → 폴더를 읽는다 → 첫 장표를 연다
```

## 저장하는 흐름

```
[Ctrl+S]
   │
   ├─ 폴더가 정해져 있나
   │     아니오 → 무엇을 왜 고르는지 알린 뒤 폴더 선택
   │              취소하면 "저장하지 않았습니다" 를 남긴다
   │     예   ↓
   │
   └─ 디스크의 원본을 가져다 붙이고 내 덧씌움만 쓴다 (core/merge.ts · mergeForSave)
         → 저장됨 표시로 바뀐다
```

## 디스크가 바뀌었을 때

```
2초마다 파일 시각만 확인 (내용은 읽지 않는다)
   │
   ├─ 글자를 고치는 중이면 아무것도 하지 않는다
   │
   └─ 바뀌었다 → 상태바에 "디스크가 더 새로움"
                  저절로 갈아 끼우지 않는다
                     │
                  [다시 읽기]
                     ├─ 저장 안 한 편집이 있나 → 있으면 묻는다
                     └─ 디스크가 더 새로우면 먼저 저장하지 않는다
                        (가져오려던 것을 덮게 된다)
```

## 규칙

- **모든 기능은 `src/app/actions.ts` 를 지난다.** 화면 조각이 `api` 를 직접 부르면
  명령 목록(Ctrl+K)에 안 나오고, 단축키도 안 붙고, 노출 누락 점검도 못 한다.
- **레지스트리에 있는데 어느 화면에도 안 나오는 액션을 두지 않는다.** 죽은 길이 된다.
  `surfaces` 가 비어 있어도 되는 것은 같은 일의 다른 단축키뿐이다.
- **되돌릴 수 없는 일은 이름을 다르게 짓는다.** "삭제"(Ctrl+Z 로 돌아옴)와
  "장표 파일 지우기"(파일이 사라짐)를 같은 단어로 부르지 않는다.
- **실패는 토스트로 알린다.** 상태줄만 쓰면 아무 일도 안 일어난 것으로 읽힌다.
