# 용어집

이 도구의 말은 대부분 한국어 도메인 용어다. 코드의 변수명·주석·화면 문구가 전부 이 어휘로
돌아가는데 정의된 곳이 없어서, 새로 온 사람은 `keepSlot` 이 왜 "빈 자리" 인지 코드를 읽어야
알 수 있었다.

근거는 [INTERVIEW.md](INTERVIEW.md). 새 저장소로 옮길 때 함께 간다.

표시 — **(새)** 는 인터뷰에서 정해진 것, 나머지는 지금 시스템에서 이어지는 말.

---

## 물건

| 말 | 뜻 |
|---|---|
| **장표** | 한 장. A4 가로 1280×905. `<section class="kg-slide">` 하나와 그 장 전용 CSS 한 덩어리 |
| **덱** | 장표의 순서. **목차가 곧 진실이다** — 폴더에 파일이 있어도 목차에 없으면 장표가 아니다 **(새)** |
| **프로젝트** | 덱 하나와 그에 딸린 자산·도형이 사는 폴더 |
| **모듈** | 장표를 이루는 시각 부품. `kgx-bars`·`kgx-donut`·`kgx-chev` 처럼 이름이 정해져 있다 |
| **도형** | SVG 로 그리는 도해. 라이브러리에서 가져온다 |

## 문서의 구성

| 말 | 뜻 |
|---|---|
| **원본(source)** | 작도된 그대로의 HTML·CSS. 한 번 만들어지면 바뀌지 않는다 |
| **오버레이** | 원본 위에 쌓인 편집분. 글자·서식·배치·구조가 여기 들어간다 |
| **덧씌움(patch)** | 한 노드에 걸린 편집분 하나 |
| **묘비** | 지운 원본 노드의 자국. 원본을 못 지우므로 표시만 남긴다. 되살리면 서식까지 돌아온다 |
| **안정 id** | 노드의 이름. **자리가 아니라 이름이다** — 표에 행을 끼워도 기존 노드의 id 는 그대로다 **(새)** |
| **리비전** | 이 문서가 몇 번째 상태인가. 내가 읽은 뒤 바뀌었으면 쓸 때 막힌다 **(새)** |

> 안정 id 가 이 시스템의 주춧돌이다. 지금 시스템은 id 가 구조 경로(`n.2.1.0`)라서
> 원본이 바뀌면 가리키는 것이 달라졌고, 그래서 AI 가 다시 그릴 때마다 사람의 편집분이
> 깨졌다. 이름이 되면 그 일이 구조적으로 일어나지 않는다.

## 배치

| 말 | 뜻 |
|---|---|
| **흐름** | KG 격자가 자리를 정하는 상태. 기본값 |
| **떼어냄** | 흐름에서 빼내 캔버스 절대좌표에 고정한 상태 |
| **빈 자리** | 떼어낸 자리에 남기는 투명한 사본. **없으면 뒤 형제가 위로 밀린다** |
| **날개** | 오버뷰 장표 왼쪽 1/3. 과업 목록 — 지금 다루는 과업만 펼치고 나머지는 접는다 |

## 글자

| 말 | 뜻 |
|---|---|
| **위계(role)** | 글자의 층. `title` `subtitle` `message` `h1~h3` `body1~4` `label` `label2` `num` `caption` |
| **말머리** | 목록 앞 기호. 빈 문자열은 "이 요소만 끈다" 는 뜻이라 전역값까지 누른다 |
| **세부주제** | 머리말 아래 한 줄. **무엇을 하는 장인지**가 여기 와야 한다(행위어로 끝난다) |

## 협업 **(전부 새)**

| 말 | 뜻 |
|---|---|
| **핸드오프** | 사람 ↔ AI 가 작업을 넘기는 일. 이 도구가 지키려는 단 하나 |
| **소유(Me / AI)** | 이 장표를 지금 누가 쥐고 있나. 한 장에는 한 손만 |
| **전역 모드** | AI 가 덱 전체를 훑는 상태. 배타적이다 — 사람은 아무 장표도 못 가져간다 |
| **메모** | 장표에 붙는 쪽지. **덮지 않고 쌓인다.** 사람도 AI 도 쓴다 |

> "무너진다" 의 뜻 — 화면이 깨지는 것이 아니라 **넘겨받은 쪽이 낡은 것 위에서 작업하는 것**이다.
> 사람이 ver0.1 을 만들었는데 AI 가 ver0.0 에서 시작하면, 이후 무엇을 잘해도 결과는 어긋난다.

## 작도 **(전부 새)**

| 말 | 뜻 |
|---|---|
| **와이어프레임** | 장표의 뼈대. 사람이 라이브러리에서 고른다. **첫 작도 때만 유효하고 그 뒤에는 구속하지 않는다** |
| **슬롯** | 와이어프레임의 한 칸 |
| **슬롯 타입** | `fixed`(머리·꼬리) · `grid`(격자) · `module`(모듈 지정) · `figure`(도형) · `free`(자유) |
