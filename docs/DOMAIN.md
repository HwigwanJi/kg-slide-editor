# 도메인 모델 — 무엇이 있고 어떻게 이어지는가

DB 가 없으므로 ERD 는 그릴 것이 없다. 대신 **문서 모델**을 적는다.
지금은 이것을 알려면 스키마 파일을 읽어야 한다.

말의 뜻은 [GLOSSARY.md](GLOSSARY.md), 왜 그렇게 했는지는 [FEATURES.md](FEATURES.md).

**여기에 필드 목록을 옮겨 적지 않는다.** 그건 계약 파일이 진실이고, 복사하는 순간 갈라진다.
여기서는 **무엇이 무엇인지와 누가 쓰는지**만 말한다.

---

## 물건과 관계

```
프로젝트
  ├─ 덱          장표의 순서.  ★ 목차가 곧 존재다 — 목차에 없으면 장표가 아니다
  ├─ 장표 N개
  ├─ 자산        그림
  ├─ 도형        SVG 라이브러리
  └─ 와이어프레임  골격 라이브러리

장표
  ├─ 원본        HTML + CSS.  작도된 그대로, 바뀌지 않는다
  ├─ 오버레이     사람과 AI 가 쌓은 편집분
  ├─ 메모        쪽지. 쌓인다
  └─ 출처        어느 와이어프레임에서 나왔나 (기록일 뿐, 구속하지 않는다)

와이어프레임
  └─ 슬롯 N개    타입 · 모듈 · 용량
```

원본을 분해하지 않고 **원본 + 덧씌운 것**으로 나누는 까닭은 저장계약 문서가 설명한다.
한 줄로 줄이면 — KG 장표는 격자·`clip-path`·그라데이션으로 그려져서, 도형 목록으로
분해하면 원본이 손실된다.

### 노드를 가리키는 법 — 여기가 주춧돌이다

오버레이는 노드를 **이름**으로 가리킨다. 이름은 작도할 때 원본에 박히고 그 뒤로 바뀌지 않는다.

지금 시스템은 이름이 아니라 **자리**(`n.2.1.0` = 3번째 자식의 2번째 자식)였다.
그래서 원본이 조금만 바뀌어도 가리키는 것이 달라졌고, 이 하나에서 나머지가 전부 파생됐다.

| 증상 | 뿌리 |
|---|---|
| AI 가 다시 그리면 사람의 편집분이 깨진다 | 자리로 가리킴 |
| 그래서 AI 만 다시 그릴 수 있다 → 힘의 비대칭 | 〃 |
| 그래서 AI 는 구조를 못 바꾼다 → 100:100 불가 | 〃 |
| 깨진 것을 건지는 방어 코드가 필요하다 | 〃 |
| 5만 번이면 누적 손실 | 〃 |

**이름으로 바꾸면 다섯이 동시에 사라진다.** 표에 행을 끼워도 기존 이름은 그대로고,
새 노드만 새 이름을 받는다. 그러면 구조 편집을 커맨드로 할 수 있고, AI 가 다시 그릴 이유가
없어지고, 힘이 같아진다.

## 누가 무엇을 쓰는가

한 파일에 주인이 둘이면 나중에 쓴 쪽이 이겨 상대의 작업이 사라진다.
그래서 **각자 자기 것만 쓴다.**

| 것 | 주인 | 언제 |
|---|---|---|
| 원본 · 캔버스 | 작도 | 장표를 처음 만들 때 한 번 |
| 오버레이 · 메모 | 사람과 AI **둘 다** | 자기 차례일 때 |
| 소유 · 리비전 | 시스템 | 넘길 때마다 |

지금 시스템은 여기서 **사람** 과 **AI** 를 갈랐다. 사람은 오버레이만, AI 는 원본까지.
그것이 비대칭의 근원이었다. 새 모델에서는 **둘 다 오버레이만 쓰고, 원본은 아무도 안 고친다.**

읽고 → 자기 것만 바꾸고 → 쓴다. 쓰기 직전에 리비전을 확인해, 내가 읽은 뒤 바뀌었으면 멈춘다.

---

## 한 장표에 한 손

같은 시각에 두 손이 닿지 않는다. 그래서 **충돌 해소가 필요 없다.**

```
사람이 2장을 쥔다        AI 는 2장에 들어오지 않는다
AI 가 3장을 쥔다         사람은 3장을 열 수 없다
아무도 안 쥔 장표        누구든 가져갈 수 있다
```

전역 모드는 예외다 — AI 가 덱 전체를 훑는 동안(예: 소제목 크기 통일) 사람은 아무 장표도
가져가지 못한다. 반쪽만 적용된 통일은 안 하느니만 못하기 때문이다.

쥔 쪽이 죽으면 심박이 끊기고 잠금이 풀린다. 전역 작업이 중간에 죽으면
**어디까지 적용됐는지가 남아야** 이어서 할 수 있다.

## 한 바퀴

```
사람이 와이어프레임을 고른다
        ↓
AI 가 채운다 — 슬롯 타입·모듈·용량을 지키며. 못 한 것은 메모에 남긴다
        ↓
사람이 이어받아 다듬는다
        ↓
검사가 넘침·겹침·글자·문구를 잡는다
        ↓
내보낸다 — 원본 또는 사본
```

가운데 두 칸이 5만 번 돈다. **이 도구가 지키려는 것은 그 왕복이다.**
